# Zero-API calibration and retrospective replay

Development instrument validation, not confirmation or a new method. New model calls = 0; USD cap = 0. No API clients, secrets or network.

Order: freeze all selected old inputs, analyzer, controls and this protocol; run every named sensitivity control; replay only if all pass; verify input hashes unchanged. Preserve the first failed attempt in a separate directory. Gold is grader-only and never fed to readers.

Inclusion fixed before replay: benchmark-v03-v1/cache-off (20 streams/160 tasks), cache-on (4/32); native-mem0-reader-v1 (both backends,12); same-evidence-calculator-reader-v1 (both arms,24); same-evidence-required-v1 (12). Total240 related tasks, not independent histories. All48 model branches share one previously authored history. Do not pool rates as population estimates.

Support uses task/source-bound structured receipts or host query/calculate certificates actually present in a saved input. Complete JSON receipt literals embedded in notes may be decoded without paraphrase interpretation; surrounding prose stays unassessed. Source-free calculator outputs are never certificates by numeric equality. Generated results absent from later actual inputs are not delivered. Initial history may be sufficient without a tool call. Current sufficient and stale evidence may coexist. Unassessed free text is unknown; a restricted calculator's failure is not an impossibility proof.

Record delivered support (sufficient/not_certified/unknown/conflicting), stale-source presence, reference mismatch and unassessed text at every actual invocation. Native prose is not labeled from the reader output or prior model semantic review. At task start separate memory support from backend-cache support. Reconstruct SQLite receipts only for IDs in that invocation's catalog, validating content addresses; no future ID access. Cache receipts use only earlier actual queries or frozen original branch seeds. Retrieval absence does not imply storage absence.

Outcome = actual correct/wrong commit, abstained, unfinished, interface failure. Generated intermediate values are distinct. Stage localization is descriptive, not causal blame. Queries while current-task evidence is sufficient are reported without assuming zero future value. Scripted and model strata stay separate.

Named controls: initial sufficiency, stored-but-undelivered, stale/current coexistence, wrong-source equality, lucky arithmetic equality, last-slot tool output, next-input delivery, joint receipts, free text unknown, conflicting certificates, tool error, sufficient-but-unfinished. Controls are engineering cases, not research samples.

No GTFS/Dask semantic labels are fabricated. Confirmation split and generalization claims are deferred. Passing this instrument does not establish method novelty, causal shares or model ranking.
