## 问题、竞争解释与预测

H-C：普通精确计算动作可减少相同实际记忆输入上的错误，或改变核验选择。竞争解释包括：reader不选择工具、数字/阈值/范围提取错误、输出变异，以及原query自带已算gate而笔记只有数值造成差异。新calculator不读取或注入任何源事实。

两臂都新取首响应，不复用原输出作为控制。control使用原reader系统提示、原query/submit/abstain动作；calculator额外允许quality_check。共同原prompt、全部原输入、query结果和后端缓存能力不变。具体任务/输入不按工具臂表现修改。改变工具可用性包含必要的工具说明token增量，记录成本；不把它归为纯文本位置效应。

保持每会话最多2动作，因此calculator和query各用一动作，下一动作提交。模型自选不调用工具是结果。非法算术参数产生显式工具错误，消耗该动作；二次query/calculate后未提交记unfinished。未知动作/不合法提交格式记接口失败，保留首输出，不补repair对话。API/JSON/截断/费用上限错误停止余下付费任务，不重试择优。
