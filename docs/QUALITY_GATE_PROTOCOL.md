# Quality-gate family: development protocol 0.3

Frozen before each suite via its file hash and code snapshot. External model calls and USD authorized by these ordinary suites: zero. This is an additional decision-semantics family over the same contingency-table representation, not a claim of independent task mechanisms or a new algorithm.

## Task

For nonnegative weighted records `(a,b,w)`, select all integer `b >= cutoff`. Return integer 1 iff this population is nonempty and its share in group `a` is at least the rational threshold `numerator/denominator`; otherwise return 0. An empty population does not authorize the gate. This decision is distinct from reporting exact selected accuracy. No floating-point threshold comparisons are needed by the public calculator.

Historical memory contains complete marginals, source-bound. Let N be total weight, C total weight in group a, and H selected population weight. The unknown selected group weight is between max(0,C+H-N) and min(C,H). A decision can be determined even when those bounds differ. These ordinary count bounds, group/full acquisition, calculation and persistence are shared capabilities, not an author mechanism.

A matching group observation can be combined with current-source marginals to obtain the numerator and denominator. A group alone lacks the denominator. After an identity change, the ordinary group policy may request full data when no current population marginal is available. The complete observation is a contingency table within this task contract, not a retained raw prediction file. Eager capture may retain it from the common historical scan at normal storage cost.

It is not eight independent histories or a held-out test. No API, data download or source redistribution occurs. Source probabilities/labels are parsed into the contracted correctness/confidence projection.

## Scoring and diagnostics

An independent raw parser plus SQLite computes labels after each whole policy stream. Runtime count bounds do not call that reference. Submitted 0/1 values actually commit even when wrong. Separate correct completion, sufficient declared evidence, unsupported lucky outputs, contradiction with adequate declared evidence, abstention, process/format failure and step limit. A declared sufficient evidence set does not mean the submitted value conforms to it.

Every planned task stays in the denominator. Persist acquired receipts to SQLite; the policy starts in a fresh process, memory is reopened. Native tool cache on/off must be common across compared policies. Source bytes count actual logical file reads; identity/scoring/history/memory/transport and process time are separate. No aggregate cost score or injected delay.

First run all ordinary policies on all four engineering fixtures and the optional native confidence archive. Preserve every result. Expected reference capability is full completion; ordinary success validates the instrument, not an author-method advantage.
