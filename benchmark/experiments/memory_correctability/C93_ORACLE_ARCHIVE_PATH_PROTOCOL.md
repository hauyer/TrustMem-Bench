# C93 原生表单修订的历史查回与预算路径

使用固定 ReScopeBench 发布版 `oracle_clinical_one_data_collection`。仅在本地原生模拟器上线，目标替换值来自公开任务。作者的 T10 示例归准备段，T01–T10 从空世界开始按普通保留策略连续执行。T11–T16 全纳入，覆盖作者既定动态变化。该工作流未参与本项目的碳信用和数仓设计，同时与其共用 ReScopeBench 上游。零模型和付费 API，无外部写入。

每个条件均在原生 17 工作单位、原生工具收费 5/3/2 和独立任务判分下运行。两种普通策略固定为公开列表原序与公开最低工作量优先。普通策略均保存来自真实工具的稳定记录句柄和 visit type，具体当前值永不复用；按 visit type 和修订类型保存候选政策及原生成功的政策，明确拒绝按范围记忆。初次无政策时按工具返回的证据 ID 排序选第一个，遇原生政策拒绝才更新，当期证据和缓存查询保持同权。未见句柄时至少需要 5 单位查询和 2 单位提交；已见句柄而无候选政策时至少需 3 单位政策查询和 2 单位提交。

每批以原序保留策略的连续原生前状态和历史为统一开局。处理对象为任务列表中第一份确有旧会话上下文回执且本轮合法可按键查回的目标；无资格均保留，分支不选号。无关删除取不在该批目标中的首个已见记录键，缺少时单列。运行保留、目标移除并不查本地原档、移除后合法按键查回及无关移除。对移除臂中实际读到同一个句柄、visit type 和公开作用域的记录，保留完整真实工具查询，只在原生收费点将这次上下文读的实收从 5 改为 0。另对基线中第一条不同目标而同为 5 单位的实际成功上下文查询做等额对照。缺少实际收费则无合格对照，原生初始额度不变。单笔减收仅用于机制诊断，普通原档为实际可执行对照。

首次执行只读取原序保留的前十批，再为全部六个后窗逐批取得移除条件的普通日志，和供下批统一起点使用的原序保留轨。以移除条件为普通诊断唯一输入。对候选收费，按实际费用之后的决策，从未办结目标中查第一个被公开工作门槛卡住的请求，减收同量后能跨过门槛就提示该目标；否则未决。减收不会预支尚不存在的余额。普通日志原样保存及加哈希。在此之后才开启真正的原档读回、指定收费和等额反事实比较，不依上述预测筛去任何目标。全量报告合法终态集合、直接与范围外变化、预算开销、未触发、拒绝、结果比较保留／原档是否逐项一致，以及诊断可见性。跨目标指不同公开记录，由各自事务判分；作用域区分句柄与可能共用的有效政策。六个批次属于同一连续历史。
