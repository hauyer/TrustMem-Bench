# P3 跨会话回执审计增量前瞻确认

## 样本和信息隔离

使用本地 ReScopeBench 冻结数据 f726fd6939a77440992dc433872acf2d2d03d158 和配套公开代码。11 个候选逐一静态检查，判定原生逐目标评分、共同额度、公开已观测回执能否在当前待办上寻址、两个派工控制是否符合原生合同。按字典序选择前五个有暖启动后匹配机会的工作流，每个只使用一条原生连续历史。每个已入选工作流的首次漂移起至末批全部纳入，覆盖两种控制和无候选批。候选模型验证版 API 工作流用于本地确定性执行，保留其上游发布状态。SkillHorizon 在固定版本逐组登记原生运行和资源可得性。全程零模型调用、零付费 API、零外部业务操作。

准入暖启动只运行变化前的原序历史，不读取对照业务终态。工程调通在变化前验证工具模式和原生成交流程。观察阶段以原序继续已有世界来获取下一批自然开局，不读取或导出连续开局轨的评分与对照结论。每批按原任务顺序确定首个在历史实际取得、作用范围可由公开键判定的回执。删除只覆盖此键，同键作用范围覆盖所有共享目标。无关移除取历史中按键排序首个不在当前目标中的同类回执。若无无关键，标记不可用。阶段三进程只读取已生成的公开 loss 文件。独立校验进程检查分母、检查点和代码封印，记录预测与输入摘要。只有验证锁后阶段四才允许执行和保存真值。控制不查询私有状态、缓存仅从实际工具返回构建，判分仅由原生 driver.grade 提供。按上游结构数据的真实绑定保留显式版本和消费规则。

## 控制与判分

原序按请求顺序，低成本优先每次按冻结公开下限排序，同价按原序。下限包含当前可见最小办理报价，未显式包含的发现或验证仍按原生账目付费。两臂共享非指定辅助缓存和原生资源限额。逐目标记录公开报价队列、前后余额、拒绝、重试资金门槛、实际动作、收费及终态。窄状态读若是 native 业务验收的一部分，随原生业务终态计分。缺乏独立发布与发布后确认事件的工作流，确认题记为不适用。

总效应比较恢复精确原档与 loss。Keep 和 archive 都独立复跑。可用的 sham 同场运行，各控制一致性原样报告。单笔费用仅在 loss 中同范围且同可复用投影读回的实际正收费处执行。只在原生计费点更改单笔收费，支付后保持其余资源限制。只有此前调用日志、当次非账目响应、实际减免额度均匹配者进入费用计分。未匹配的收费分支保留、单列。真值为原生终态方向和得失目标身份，净减也单列。真实新增与失去的目标逐一标注是否在已登记直接作用范围。

对费用真值变化的单位，遍历同轨其他成功且收费不低于原指定复查的调用，使用相同减免量，并记录可得到同一终态者及范围外替代者。总效应中低成本优先确实换序且终态变化时，额外复跑顺序交叉。两种固定顺序下的回执干预若得到不同的有向目标变化，记录交互。两项检查提供可观察的归因歧义下界。

## 盲诊断与成本

D0 读直接完成、整批计数、预算停止。D1 只估计同值复查免除之后首次晚到未启动目标是否跨门槛。D2a 支持发布后单纯确认、初始及逐步公开报价变化、拒绝后重试费及未启动门槛。无法判定目标多重竞争、可能换序、只有下限的未知路线或明显的后续路径切换时允许未决。D2b 在 D2a 未决时对同样可见的成本和办理顺序做静态分配。准确要求终态类别、净增目标集合和净失目标集合全相同。未决与错判分别记，错误可同时符合漏判、误报、错指对象中的多个标签。D2b 根因从已锁定的 D2a 分歧理由或原生控制支持判定，未证实记 other。

按两问题分别计算全量最小重放（只运行目标问题的对应反事实）、完整审计（含对照、适用的顺序交叉和等额减费），以及 D2a 只对未决行重放。分别报告节省、残留确定误判、准确率和有业务意义的纠错分母。两问题的完整成本按整个配对单位记，避免重复相加。记录每个分支原生工具调用数、检查点恢复次数、从恢复到评分及关闭的本地壁钟时间，包含并行工作进程争用；实际壁钟值保留每次运行的原值。独立复跑的确定性产物应逐字节一样，计时不会纳入相等断言。诊断所需日志采集与正常运行共同；报告追加重放成本。每工作流一条独立历史，批次和两策略重复配对。没有总体显著性检验。验收运行完成后交接现有工程及新增实验数据。
